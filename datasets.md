# Dataset Reference

- `scikit-learn.datasets.load_iris`: public Iris flowers dataset; official guide: https://scikit-learn.org/stable/datasets/toy_dataset.html#iris-plants-dataset
- `load_wine`: public wine chemical analysis benchmark (chapter 19); see the scikit-learn dataset guide.
- `load_breast_cancer`: public diagnostic benchmark (chapter 26). Educational evaluation only, not clinical use.
- `load_diabetes`: scikit-learn standardized regression benchmark used in chapter 36 / project 2. The target is a quantitative disease-progression measure, **not** a diabetes diagnosis.
- `load_digits`: public 8x8 image benchmark (chapter 32 / projects 5 and 6).
- `make_blobs`, `make_moons`: scikit-learn synthetic toy generators.
- All other examples use synthetic NumPy-generated or hard-coded illustrative data and are marked as synthetic or toy in the code / PDF.

Before redistributing or applying an external dataset, consult its individual attribution and licensing requirements. Avoid treating toy splits or fabricated sensor readings as evidence of real-world accuracy.
